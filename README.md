# ✈️ TravelBook — Travel & Hotel Booking Platform

A full-stack travel and hotel booking web application built using the MERN stack.

## 🚀 Features

- 🔐 User authentication
- 🏨 Hotel browsing and booking
- ✈️ Travel destination management
- 💳 Stripe payment integration (Test Mode)
- 📱 Responsive design
- 🔎 Search and filtering
- 👤 User-friendly interface

## 🛠️ Tech Stack

### Frontend
- React.js
- Tailwind CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB
- MongoDB Atlas

### Other
- Stripe
- REST APIs
- Git & GitHub
